# 写回实验：转场 / 第二条 video 轨 / 片段级淡入淡出（2026-10-28）

`write-rules.md` 是 M3 的依据，而 M3 **未开工** —— 那份文件里的九步事务、内容不变式都还没有任何一条被写回本身验证过。
本文件记录一次**在草稿副本上**的受控写入，目的只有一个：把「规格说结构是这样」推进到「照这个结构写进去，读回来还是这样」。

**等级**：结构一致性 = 结构校验 + 回读比对；渲染可见性 = 通道 2 离屏帧（单例）；
**剪映能否正常打开 = 未验证（open，等人在环里重开）**。

## 环境与只读证明

| 项 | 值 |
|---|---|
| 源草稿 | 恒锋齿条丝锥访谈成片（只读，实验期间 sha256 不变） |
| 实验副本 | 同目录下整目录复制（含 `Timelines/` 与根镜像），时间线 id 不变 |
| 写入方式 | `jianying-editor` 的整值写回：解密 → 内存改 → 逐副本原子写 → 回读 |
| 写前备份 | 两份 `draft_content.json` 复制到 `temp/exp-backup/`，另有写回器自带的 `.jianying-editor-backups/<stamp>` |
| 结构校验 | 引用完整性、同轨不重叠、顶层 duration = 最大结束时间：**errors 0**（warnings 是同源就有的 `target != source/speed`，与本实验无关） |

## 写进去的三样

| # | 层 | 做法 | 回读结果 |
|---|---|---|---|
| W-1 | 第二条转场 | 深拷贝既有转场文案的**同一条资源包**（`resource_id`/`path` 不变），新 id、`duration` 改 400000、`is_overlap` 保持 true，追加到另一个切点**前一段**的 `extra_material_refs` | `materials.transitions[]` 由 1 变 2；两条分别挂在 8.86–10.40 s 与 38.36–39.70 s 的段上，下一段起点差仍为 0 |
| W-2 | 第二条 video 轨（画中画） | 克隆既有画中画轨的**键集**（`attribute`/`flag`/`id`/`is_default_name`/`segments`/`type`），`flag=2`、`attribute=1`；片段深拷贝，其 `extra_material_refs` 指向的每条材料**逐个深拷贝并重指**，不共享 `speeds`/`beats`；插在最后一条 video 轨之后 | 轨数 11 → 12，新轨 `flag=2`，1 段落在 62.00–64.00 s；悬挂引用 0 |
| W-3 | 片段级淡入淡出 | 按真实条目形态新建 `{id, type:audio_fade, fade_in_duration, fade_out_duration}`（**不生成** `fade_type`/`in_type`/`out_type`），挂到一条音效段的 `extra_material_refs` | `materials.audio_fades[]` 由 2 变 3；淡入 0.15 s / 淡出 0.20 s 挂在 37.02–37.74 s 的音效段上 |

## 渲染侧验证到什么程度

- **W-2 有像素证据**：离屏通道（`render_frame.py`，同律 PIL+ffmpeg）在 62.500 s 出图，副本显示的是新增轨的那条素材（手部与丝锥近景）覆盖主画面，
  字幕仍在最上层；同一时刻的原草稿是全景。⇒ 新轨被读入绘制序，且没有把文字压掉。
- **W-1 没有像素证据**：该通道**明确不应用转场**（工具自述的已知限制），只能验到「材料被引用、结构合法」。
- **W-3 没有可听证据**：混音在浏览器通道里才有；结构上只能确认材料挂到了片段上。

所以这三条里，只有画中画这一条从「结构合法」走到了「渲染可见」。

## 还没验的那一半

1. **剪映重开是否报修复 / 重建**：`write-rules.md` 的最终验收就是这一条。本实验只做到通道 2，需人在环里开一次副本。
2. **`is_overlap: true` 的真实含义**：复制时沿用了原值；「片段不吃掉 d/2」在结构上成立，但渲染窗口落在切点哪一侧仍未判（半窗假说）。
3. **`flag=2` 之外的轨属性**：新轨的 `attribute=1` 也是克隆来的，桌面语料里它对应什么面板语义没有正向证据。
4. **多副本一致性**：本次写的是「活动时间线副本 + 根镜像」两份；非活动时间线与 `.bak` 未参与，混合状态的恢复路径（九步事务的第 9 步）没有被真正触发过。

## 这个实验**不**能得出的结论

- 不能据此说 M3 可以开工：九步事务里「快照 → 变更 → 校验 → 失败回滚」只走通了顺路，回滚没被触发过。
- 不能把 `flag=2` / `audio_fade` 的写法升 verified：一次成功写入只证明「这组值没被这一条草稿拒绝」，
  与 `scope.md` §6.1 要求的「字段合法面 + 语料实测」两路都还不是同一路证据。
- 不能把通道 2 的一张帧当成验收：`playback_check.py` 是唯一裁判，单张截图不算。
